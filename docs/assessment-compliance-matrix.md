## 2. Gap Analysis & Resolved Items

1. **Microphone Permission & Continuous Listening:**
   - **Pre-Audit Issue:** Speech recognition stopped after silence, leaving the UI stuck on `"ARIA LISTENING..."`.
   - **Resolution:** Added explicit `getUserMedia` pre-flight check in `App.jsx`, automatic 120ms restart on silence (`onend`) in `CallInterface.jsx`, and a direct audio recording button (`MediaRecorder`) for Groq Whisper STT.
2. **Mobile Responsiveness Cutoff:**
   - **Requirement Check:** Fix observed issue where dashboard's right column (Orders Helper) was cut off on mobile viewports.
   - **Resolution:** Updated CSS and container styles to ensure fluid 1-column wrapping below 960px.
3. **Markdown Artifacts in Speech:**
   - **Requirement Check:** Strip asterisks (`**bold**`) and markdown symbols from text before sending to speech synthesis so Aria sounds natural.
   - **Resolution:** Added markdown stripping sanitization prior to speech synthesis utterance creation.
